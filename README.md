# parking-

เว็บแอปบันทึกการจอดรถ (ไฟล์เดียว `index.html`) ใช้งานบนมือถือ แล้วพิมพ์/บันทึกเป็น PDF ได้

## วิธีใช้
1. เปิด `index.html` บนมือถือ (หรือผ่าน GitHub Pages)
2. กรอกทะเบียน เวลาเข้า โซน หมายเหตุ ถ่ายรูปได้ แล้วกด **บันทึก**
3. กด **บันทึกออก** เมื่อรถออก
4. เลือกช่วงวันที่ แล้วกด **🖨️ พิมพ์ / บันทึกเป็น PDF**
   - iPhone (Safari): กด แชร์ → Print/พิมพ์ → กางนิ้วที่ภาพตัวอย่าง → แชร์ → บันทึกไปยังไฟล์
   - Android (Chrome): เลือกเครื่องพิมพ์ "Save as PDF / บันทึกเป็น PDF"
   - ปุ่ม **PDF** ในแต่ละรายการ = พิมพ์เฉพาะรายการนั้น

ข้อมูลเก็บในเครื่อง (localStorage) ของมือถือเครื่องนั้นเท่านั้น
